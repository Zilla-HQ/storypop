## 5. Generation prompts — StoryPop's agent skill

This is where StoryPop diverges hardest from the template. The template's preview chain is photo → staging. StoryPop's is form → story → 16 illustrations → PDF.

### Required — rewrite
- [ ] **`lib/falai.ts`** — rewrite around two generators:
  - `generateCoverIllustration(book, characterLora)` — Nano Banana Pro + character LoRA. Style preamble: "warm picture-book illustration, slightly painterly, no text in image."
  - `generatePageIllustration(book, pageNumber, sceneDescription, characterLora)` — same generator, per page.
  - `lockCharacter(photoUrl) → loraId` — trains a 3-shot character LoRA against the uploaded photo. If no photo, picks a default character archetype.
- [ ] **`lib/claude.ts:draftStory`** — system prompt: "You are a children's book author. Draft a 12–16 page story for [name], age [age], pronouns [pronouns], in the [archetype] archetype. Match the age-band reading level. Each page is 1–3 sentences. End each page with a beat that gives the illustrator a clear scene." Output: structured JSON `{title, dedication, pages: [{sceneDescription, body}]}`.
- [ ] **NEW: `lib/claude.ts:storySafetyGate`** — runs after `draftStory`. Refuses: violence beyond mild peril, romance/sexuality, real-world political figures, branded characters (Disney/Marvel/Pokémon/Bluey), substance use, weapons. Re-prompts up to 2× with refusal reason, then escalates to operator.
- [ ] **`lib/claude.ts:draftOutreachEmail`** — delete (no cold outreach). Repurpose as `lib/claude.ts:draftAbandonedCart`: warm follow-up if a parent generated a preview but didn't buy within 24h.
- [ ] **`inngest/functions/outreach.ts`** → delete, replace with `inngest/functions/abandoned-cart.ts`.
- [ ] **`lib/claude.ts:classifyReply`** — categories: `refund_request`, `print_question`, `edit_request` (spelling fix), `gift_inquiry`, `complex`.

### Don't touch
- `lib/claude.ts:callClaude`
