# Capabilities catalog — what's in and what to copy from Sitebeat / Relist

> Every gap between this template and the live reference merchants ([Sitebeat](https://github.com/Zilla-HQ/sitebeat), [Relist](https://github.com/Zilla-HQ/realestate), [Restay](https://github.com/Zilla-HQ/airbnb)), with **exact file paths** in both repos so you can grab patterns directly when needed.

> **Status, May 2026:** Most of Sitebeat's distinctive patterns are now ported into this template — affiliate, sponsor outreach, abandoned-checkout, direct mail, programmatic SEO, spectacle layer, Google Ads autonomy runtime, 4-touch follow-up, weekly digest. See [SITEGRID_REFERENCE.md](./SITEGRID_REFERENCE.md) for the full provenance + per-capability file pointers. (Sitebeat was previously called SiteGrid; the legacy name is preserved in the reference doc filename.)

> Sitebeat was the prototype known as "SiteGrid" before rebranding — most references in this doc are to its current `Zilla-HQ/sitebeat` repo path.

This is a working catalog, not aspirational architecture. Sitebeat pushed many platform patterns further than the original Realscale base. Some are ported into this branch (✅), some are documented here for copy-paste when a forker hits the same need (📋).

If you're wiring a fresh merchant and want to know "does the template handle X?", grep this doc first.

Full breakdown in [ENRICHMENT.md](./ENRICHMENT.md).

## How to use this catalog

**Forking a new merchant?**
- ✅ items are already in the template — use them directly
- 🟡 items have base infrastructure but need a small upgrade — read the Sitebeat reference, copy what's missing
- 📋 items aren't in the template — when you hit the use case, the file paths above tell you exactly where to read

**Promoting a 📋 to ✅?**
1. Read the Sitebeat file
2. Adapt the pattern to your stack (Next.js + Inngest + Drizzle vs. Express + node-cron + Drizzle)
3. Open a PR back to merchant-template promoting it from 📋 → ✅, with the file paths in this catalog updated

**Disagreements with priority?**
The audit ranked items based on observed business impact in Sitebeat. Your merchant might weight differently — e.g., if you're not running cold email, the enrichment backfill drops to LOW. Adjust as you fork.
