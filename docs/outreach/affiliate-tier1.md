# Sending notes

- **Open with the personal observation** — every email above has one specific thing that proves you actually paid attention to their content. Update it before sending if anything's stale (their latest episode, a recent video, a recent post).
- **Don't BCC**. These need to feel personal.
- **Wait 7 days, then a one-line bump.** "Hey — bumping in case this got buried, no pressure." That's it. Don't bump twice.
- **Tier-2 list (post-Tier-1):** mid-size STR coaches with <10k audiences. They convert *better* than Tier-1 because the relationship is tighter. Build a list of 50 over 30 days from Twitter/IG/YouTube searches for "airbnb host coach" and run a less personalized batch.
