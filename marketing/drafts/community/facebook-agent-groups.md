# Facebook agent group posts

Big agent groups (5K–80K each):
- "Lab Coat Agents Marketing Center" (~120K)
- "REAL ESTATE AGENTS - Realtors Helping Realtors" (~80K)
- "REALTOR® Mastermind" (~50K)
- Your local "{State} Real Estate Agents" group
- Top Producers of Real Estate (~30K)

Rules: most groups ban link drops on sight. The pattern below leads with the value (free score), buries the link 3 lines deep, and asks for feedback — that gets through most mod filters.

---

## Post variant A — quiz hook

```
Q for the room: when you're scrolling Zillow as a buyer, how many seconds do you give a listing's photos before you swipe past?

I built a free 1–5 photo score tool because I was curious if MY OWN listings would survive that test. Spoiler: they didn't. 😬

It's at realscale.app/tools/photo-score (no signup, no email — just paste a Zillow URL).

Would love this group's gut-check: does the score it gives match what you'd give the same listing? Curious if my model is calibrated right or if it's grading too hard.
```

```
realscale.app/tools/photo-score

Genuinely free. Drop your toughest listing in the comments and I'll run it for you.

```

```
I built a faster version. $89 per listing flat (every interior photo, not per-photo), <2 hours, NAR disclosure stamped. There's also a free "score my photos" tool — link in comments because I don't want this to read as a plug.
```

---

**Posting cadence:**
- One group per day for 5 days
- Rotate variants — never post the same copy in two different groups in the same week
- Engage with every comment within 30 minutes of posting; that signals "real conversation" to FB's ranker
